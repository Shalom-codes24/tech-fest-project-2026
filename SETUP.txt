Connect registrations to Google Sheets
======================================

1. Create a Google Sheet for Jos TechFest registrations.
2. In the sheet, open Extensions > Apps Script.
3. Replace the editor contents with Code.gs from this folder, then save.
4. Select setup and click Run. Approve access so the script can add a
   Registrations tab to this spreadsheet.
5. Click Deploy > New deployment. Select Web app.
   - Execute as: Me
   - Who has access: Anyone
6. Deploy, approve the requested permissions, and copy the Web app URL ending
   in /exec.
7. In index.html, replace the empty value for SHEETS_WEB_APP_URL with that URL.
8. Save index.html and publish it wherever you plan to host the form.
9. Submit a test registration and confirm a row appears in the Registrations tab.

The public Web app URL accepts registrations from anyone who has it. Keep the
linked spreadsheet private, and redeploy the web app if you change Code.gs.
